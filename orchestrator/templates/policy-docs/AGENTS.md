# {{PROJECT_NAME}} - AI 개발 지침

이 파일은 AI 에이전트가 프로젝트를 진행할 때 항상 참고해야 하는 핵심 지침입니다.

## 1. 프로젝트 핵심

- **목적**: {{PROJECT_GOAL}}
- **가장 중요한 가치**: 빠른 사용자 경험, 안전한 인증/권한 처리, 재현 가능한 검증.

## 2. 기본 기술 구조

- **Web**: React, TypeScript, CSS Modules.
- **Backend Core**: Java Spring Boot. 계정, 인증, 권한, 기록, 핵심 비즈니스 규칙을 담당합니다.
- **Backend Fast/Hot Path**: Rust. 지연 시간이 중요한 업로드, 실시간, fan-out, 스트리밍 경로를 담당합니다.
- **Mobile**: Android Kotlin. 촬영, 업로드, 인증 토큰 저장/복원, 백그라운드 전송을 담당합니다.

## 3. 개발 방법론

- `.skills` 디렉토리에 모듈별 검증 스크립트를 둡니다.
- 코드를 수정하면 관련 `.skills/verify-*.ps1` 스크립트를 실행해 검증합니다.
- 새 시스템을 추가하면 필요한 검증 스크립트도 함께 추가하거나 기존 스크립트에 반영합니다.
- MCP는 꼭 필요한 경우에만 사용합니다.

## 4. 코딩 정책

- 기존 계약, 환경변수 이름, 인증 구조를 임의로 바꾸지 않습니다.
- 계약 변경이 필요하면 master/manager에게 명시적으로 보고하고 승인을 받은 뒤 진행합니다.
- 의존성 추가 시 최신 안정 버전을 우선 고려하되, 프로젝트 프레임워크와 검증 스크립트가 통과해야 합니다.
